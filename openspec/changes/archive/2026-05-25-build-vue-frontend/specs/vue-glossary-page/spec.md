# Spec — vue-glossary-page (ADDED)

## ADDED Requirements

### Requirement: Domain/category tree with search

The Glossary page SHALL display a left panel with a collapsible tree of domains and categories. A search input above the tree SHALL filter terms by title. Selecting a term SHALL display its detail in the center panel.

#### Scenario: Tree reflects glossary structure

- **GIVEN** the glossary is loaded from `GET /glossary`
- **THEN** the tree SHALL show domains as top-level nodes, categories as children, and terms as leaves
- **AND** each node SHALL show a count of terms within it

#### Scenario: Search filters the tree

- **WHEN** the user types in the search input
- **THEN** the tree SHALL filter to show only terms whose title matches the query
- **AND** parent nodes with no matching children SHALL be hidden

### Requirement: Term detail with per-section inline editing

The center panel SHALL display the selected term's sections: Definition, Business Context, Related Objects, Source Context, and any additional metadata. Each section SHALL have a pencil icon to toggle edit mode.

#### Scenario: Edit a section

- **WHEN** the user clicks the pencil icon on a section
- **THEN** the section content SHALL become editable (text area)
- **AND** Save/Cancel buttons SHALL appear
- **AND** saving SHALL call `PUT /glossary/terms` and show a confirmation toast

#### Scenario: AI-generated badge

- **GIVEN** a field was generated by AI
- **THEN** an "AI-generated" badge SHALL be displayed next to the field

### Requirement: New term creation with pre-fill

A "New Term" button SHALL open a creation form with fields for title, domain, category, definition, and related objects.

#### Scenario: Pre-fill from incoming navigation

- **WHEN** the page loads with `route.query.new=true` and additional query params (title, source, table)
- **THEN** the new term form SHALL open with those fields pre-filled (replaces Streamlit's `_gloss_new_prefill_pending`)

### Requirement: AI-assist panel

A toggleable right panel SHALL provide a chat-like interface for AI-assisted term generation. Submitting a prompt SHALL call `POST /glossary/terms/{id}/ai-suggest` and update the term fields with the response.

### Requirement: Uncovered concepts discovery

A tab or section SHALL show a grid of catalog items not yet covered by glossary terms. The grid SHALL be filterable by source, object type, and field name.

#### Scenario: Navigate from uncovered concept to catalog

- **WHEN** the user clicks "Review in Catalog" on an uncovered concept
- **THEN** the app SHALL navigate to `/tools/catalog?dataset={dataset}&table={table}`

#### Scenario: Create term from uncovered concept

- **WHEN** the user clicks "Add Term" on an uncovered concept
- **THEN** the new term form SHALL open with context pre-filled from the concept

### Requirement: Incoming navigation and deep-linking

- **WHEN** the page loads with `route.query.term` set
- **THEN** the corresponding term SHALL be auto-selected in the tree and displayed in detail
